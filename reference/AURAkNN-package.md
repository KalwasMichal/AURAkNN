# AURAkNN: Accelerated Ultra-rapid R Architecture for k-NN imputation

AURAkNN implements high-performance k-Nearest Neighbors (kNN) imputation
algorithm. It features a highly optimized C backend with OpenMP
multithreading, supporting Euclidean, Manhattan, and Gower distances,
and operates in two distinct modes: fast and precise.
